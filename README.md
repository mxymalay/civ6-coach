# 文明 VI 陪练 · macOS

原生 SwiftUI 中文陪练：读取《文明 VI》局势，解释本回合该优先做什么，支持继续追问。无需反复截图，不替玩家操作游戏。

适合想边玩边学、又不想频繁切出游戏截图的新手玩家：在主窗口分析局势，在聊天里追问原因，也可以把透明建议小窗固定在游戏旁边。

## 下载与安装

**最新版本：v0.8.5** · macOS 13 及以上 · 本次预编译包为 Apple Silicon（arm64）。Intel 用户请尝试从源码构建，尚未验证。

[下载 macOS 安装包](https://github.com/mxymalay/civ6-coach/releases/download/v0.8.5/文明VI陪练-0.8.5-macOS.zip) · [查看所有版本](https://github.com/mxymalay/civ6-coach/releases)

1. 下载 ZIP 并解压，将「文明 VI 陪练 0.8.5.app」移到「应用程序」目录。
2. 按下方「连接游戏」说明启用本机 Tuner，重启游戏并进入单人地图。
3. 打开陪练，在设置中填写自己的 API 地址、模型与密钥，测试并保存。
4. 点击「建议」获得行动提示，或进入「和老师聊聊」提问。菜单栏「文」打开普通快捷卡片，卡片内可切换透明模式。

应用为 ad-hoc 签名，未经过 Apple 公证。若 macOS 阻止打开，请先确认下载来源，再按系统提示到「系统设置 → 隐私与安全」允许打开；不要关闭系统安全保护。升级前退出旧版本，配置和本机聊天独立保存在用户目录，不随应用包替换。

## 功能

- 聊天页「历史对话」按时间倒序展示本机归档，支持只读查看，不覆盖当前对话、不把旧局历史加入 AI 上下文。损坏归档保留并提示。

- 透明小窗首次进入显示可关闭的操作引导；右键可重新查看引导，或调整字号、字体、颜色、阴影。设置的「透明小窗」页可禁用首次引导、重新引导及调整文字样式，这些偏好即时保存。四角双描边标示缩放位置。

- 只读获取自身经济、城市、生产、研究、单位，以及所有己方城市与单位周围 3 格的当前可见地图。
- 回合变化在本机比较：新增城市、人口、住房、生产项目、金币收入转负、科技解锁、新观察到的敌军。不自动调用 AI。
- 即时基础提醒（无需 AI）、一键 AI 建议、多轮中文聊天。
- 快速建议默认最多三条、目标 180 字以内；请求带输出预算，客户端正文另有长度上限。超限会停止接收并保留已有内容，不把截断回答当成完整回复。
- 自定义 OpenAI 兼容 API：Chat Completions / Responses，支持本机 HTTP；远程要求 HTTPS。
- 打开应用后自动读取游戏局势；菜单栏「文」图标可打开小窗查看建议、快速生成、进入聊天。
- 主窗口右上角图钉可独立切换并记住置顶状态；设置页不再放置主窗口置顶开关。
- 普通卡片使用紧凑标题与底部小按钮；图钉只控制固定，不改变透明度。未固定时点击外部自动收起。
- 虚线矩形图标进入透明游戏叠加层并自动置顶；实心矩形图标退出透明，恢复原来的普通卡片固定状态。透明层仅保留建议、淡虚线边框与低调的生成/退出图标，无实色底板、大按钮或常驻缩放图标。
- 拖动透明层顶部空白移动；四边有 8 像素、四角有 14 像素缩放热区。两种模式分别记住尺寸，透明最小 240×120、普通最小 320×280。
- 普通和透明模式均由原生窗口接管顶部非按钮区域的拖动，支持上下左右移动；固定只表示置顶，不锁位置。正文保留滚动和文字选择，边框仍用于缩放。
- 透明层右键（或 Control+单击）打开菜单，可生成/停止建议、调整文字、查看操作引导和「退出透明」；退出恢复普通卡片，不退出应用。未配置 API 时，「生成建议」会禁用。
- 应用内快捷键：⌘⇧J 显示/收起小窗，⌘⇧O 固定/取消固定普通卡片，⌘⇧G 切换透明；不是游戏内全局热键。生成图标按当前状态执行配置 AI、快速建议或停止生成；切换模式或固定本身不发送 AI 请求。
- 透明不等于整个窗口鼠标穿透；文字、按钮、滚动和拖动区域仍可交互。建议移到地图边缘；点击菜单栏「文」先恢复普通卡片，再次点击收起。跨游戏全屏的置顶效果取决于 macOS 与游戏显示模式，窗口化/无边框模式更适合叠加使用。
- 设置分为「API」「外观」「透明小窗」「陪练与隐私」四页。外观页将强调色（森林绿、海军蓝、暮光紫、石墨黑、银灰）和深色/浅色/跟随系统分开设置；旧版「纯白」主题会迁移为银灰强调色加浅色外观。透明小窗偏好即时保存，其余设置点击保存后持久化。
- 设置页和聊天页的输入框、设置分类及选项条使用统一的主题样式；聚焦输入框会显示强调色边界。
- 主页精简为当前回合、资源摘要、关键提醒和老师建议；教程式欢迎卡与重复说明已移除。
- 强调色及深浅外观跨窗口实时预览，取消或关闭设置恢复原外观。透明 HUD 保持独立文字样式。
- 可停止生成；API Key 保存在 macOS 钥匙串；对话可本机保存、归档、导出。

## 构建

需要 macOS 13+、Xcode / Swift 5.9+。已在 Apple Silicon Mac 实测，Intel 未实测。

```sh
git clone https://github.com/mxymalay/civ6-coach.git
cd civ6-coach
./build.sh
open "dist/文明 VI 陪练.app"
```

产物为本机 ad-hoc 签名，不是经过 Apple 公证的发行版。桌面应用不需要 Python。

## 连接游戏

1. 退出《文明 VI》，备份 `AppOptions.txt`。
2. 仅将 `EnableTuner 0` 改为 `EnableTuner 1`。
3. 重启游戏，载入单人存档进入地图，再打开陪练应用；应用会自动连接。

Steam macOS 常见配置位置：

```text
~/Library/Application Support/Sid Meier's Civilization VI/Firaxis Games/Sid Meier's Civilization VI/AppOptions.txt
```

**启用 Tuner 会影响游戏成就。** 应用不自动修改配置。恢复时退出游戏，仅改回 `EnableTuner 0`，不要用旧备份覆盖后来更改的其他选项。
连接失败时确认游戏已重启、地图已载入、没有其他 FireTuner 客户端占用连接。仅连接 `127.0.0.1:4318`，不对外开放端口。

## 配置 AI

在设置的「API」页配置服务。应用已移除 Codex 登录和 CLI 调用功能；升级保留原有 API、主题及其他偏好，不修改本机 Codex 账号。

支持多套 API：用配置选择器切换，旁边的加号、铅笔和垃圾桶分别新增、重命名和删除，保存后生效。每套独立保存地址、模型、接口类型和钥匙串密钥；旧版配置自动保留。聊天输入区左下角显示「配置名 · 模型名」，可直接切换已保存的配置，生成期间禁止切换。删除配置会在保存时删除对应密钥；取消不会修改密钥。

填写服务地址、模型 ID 和 API Key，测试并保存。本机无鉴权服务可留空密钥。密钥不写入项目或设置 JSON；更换地址时输入框清空旧密钥。测试和生成会消耗所选服务的用量或费用。

「学习目标」提供基础运营、科技胜利、文化胜利、征服胜利、宗教胜利五个选项，也可选择自定义。目标作为附加指导传给 AI，不会替换安全和局势读取规则。

## 隐私与限制

- 查询在本机执行；点建议/发送聊天时，局势和必要对话会发送到选中的 AI 服务。刷新局势不调用 AI。
- 关闭应用会停止本机局势轮询；可单独停止正在生成的 AI 回答，已发送的请求不保证退回用量。
- 只读取自身及当前可见信息，不窥探迷雾。城市与单位周围地图去重，最多 4000 地块；发给 AI 的地块细节均匀抽样至最多 240 条，单位最多 400 条，明确标注采集及抽样限制。不能据此判断整个帝国安全。
- 回合提醒从应用连接后的下一次回合变化开始；同回合刷新更新同一组比较，不重复追加。跳过多回合时显示汇总。读档回退或文明变化重置比较；生产项目变化不能直接当成已完成，敌军新出现也可能只是视野变化。最多显示 12 条重点变化。
- 固定 Lua 没有移动、建造、结束回合或任意脚本入口。FireTuner 本身是调试接口，勿暴露到外网。
- 缺失字段是未知，不当作零。快照不是引擎原子事务，查询时尽量不要结束回合。
- 回合倒退或文明变化会开启新对话；无法识别所有同文明/同回合换档，换局后请手动「新对话」。
- 重启应用后仍显示保存的旧对话，但不会把上次会话自动发给 AI，避免误用另一存档的历史。
- AI 可能有误，不是精确规则引擎或最优策略求解器。主要验证单人 Steam Mac 版，不同 DLC/Mod 可能有缺失字段。
- 对话保存在 `~/Library/Application Support/Civ6Coach/`。关闭保存会移除当前对话副本，历史归档仍保留。`--qa` 使用独立偏好及对话目录。

## 测试

```sh
swift test
# 可选：需游戏已载入，会读取真实游戏数据
CIVCOACH_LIVE_TEST=1 swift test
# 可选：使用当前 API 配置发送一条模拟场景请求，会消耗少量 API 用量
CIVCOACH_LIVE_API_TEST=1 swift test --filter LiveAPIRegressionTests
```

默认测试用本地 HTTP 服务检查流解析、中文片段、错误、取消及 JSON 回退，不需真实 API Key。可选 Python MCP 桥接器见 [bridge](bridge/README.md)。
